# Sistema de Pedidos de Comida Local - Cusco

## Descripción
Proyecto inicial de una aplicación web para gestionar pedidos de comida local en Cusco. Se utiliza Git y GitHub para organizar el código y registrar sus cambios.

## Objetivo
Preparar un repositorio para el desarrollo colaborativo de un sistema de pedidos.

## Funcionalidades propuestas
- Consultar platos disponibles.
- Registrar pedidos de clientes.
- Consultar el estado de un pedido.
- Administrar el menú.

## Herramientas
- Visual Studio Code
- Git
- GitHub

## Estructura del proyecto
- `README.md`: información y documentación inicial.
- `index.html`: página de inicio de demostración.

## Cómo ejecutar
Abrir `index.html` en un navegador web.

## Control de versiones
El proyecto usa Git para registrar cambios y GitHub como repositorio remoto.

## Reflexión
**¿Por qué Git es crítico en proyectos colaborativos?** Porque permite que varias personas trabajen sobre un mismo proyecto, registren quién hizo cada cambio y mantengan un historial de versiones.

**¿Qué problemas evita?** Evita perder cambios, sobrescribir accidentalmente el trabajo de otros y tener múltiples copias desordenadas del mismo proyecto. También permite recuperar versiones anteriores.
